After learning something new, the next thing we usually must do is to

## Description

Appropriate Practice Activities

Starting out with string, keyword, help, as well as a built-in function
overview, Python 1200 will guide new students through a series of
logical, evolutionary, hands-on practice activities. From collection
types to chess boards and fundamental research & testing concepts,
students looking to be inspired with an informative set of practice
activities should find Python 1200: Practice for Beginners to be both
challenging, as well as educational.

From keywords & tabs, to testing & documentation, hints & tips on how to
use Python in the professional world abound!

After completing the Python 1000 series, in the Python 2000 series
students will complete keyword mastery by exploring a large collection
of activity-related topics. Sold separately, in the 2000 series students
will enjoy learning how to create Lambdas, Generators, Context Managers,
Packages & Modules, Classes, Factories, Frameworks, how to manage
Exceptions, as well as other professional programming topics.

About This Series

Written by a Principal Trainer & Principal Software Development

## Lessons

100: Beginner's Practice: Welcome!

Surely the greatest assumption behind any professional is that we enjoy
what we're professing well enough to be practicing - and keeping up with
our profession! 🤓

---

200: Act 1, Scene 1

Practice how to clear the screen, use the help subsystem, as well as to
perform basic operations.

---

300: Act 1, Scene 2

Review how to re-use ours, as well as standard, functions.

---

400: Act 1, Scene 3

Practice iteration by reviewing the use of the \`for\` keyword.

---

500: Act 1, Scene 4

Understand how Unicode expands the ability to display national languages
and interesting glyphs in Python 3.

---

600: Act 1 Solution, Scene 1

Create a function to clear the screen that displays the name of the
active file.

---

700: Act 1 Solution, Scene 2

Review a solution to the chessboard activity.

---

800: Act 2, Scene 1

Practice how to create a function that accepts various forms. and types,
of parameters.

---

900: Act 2, Scene 2

Review how to create functions that require parameters, as well as how
to encode default values. Review how to format using Python's two (2)
string formatting conventions.

---

1000: Act 2, Scene 3

Review how to create and convert data between commonly-indexed data
types. Under how using Python's built-in \`set()\` collection type has
helped us analyze data.

---

1100: Act 2, Scene 4

Review several ways to create a calculator in Python.
